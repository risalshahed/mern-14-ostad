## Download & Run the Project

### Clone the Repository
```bash
git clone https://github.com/risalshahed/mern-14-ostad.git
```

### Switch to the Branch
```bash
git switch module-22-payment-server
```

### Install Dependencies
```bash
npm i
```

### Run the Server
```bash
npm run dev
```
